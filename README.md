## 〔 `> ls ./projects` 〕

### Memristor Emulator — Research Migration to eSim

Completed a research migration under the **FOSSEE, IIT Bombay** initiative, publicly listed on the eSim website. Reproduced a published decremental memristor-emulator circuit using op-amps, NMOS/PMOS current mirrors, and capacitor-based state storage. Implemented a four-quadrant analog multiplier as a behavioral SPICE subcircuit.

**Tools:** eSim · ngspice · Behavioral SPICE modeling  
[View completed research migration →](https://esim.fossee.in/research-migration-project/research-migration-run/794)

### AlgoPipe — ML Pipeline Generator

Developed and published a Python package with an interactive CLI that generates customizable machine-learning pipeline templates. Modular preprocessing and model-configuration components help automate repetitive project setup.

**Tools:** Python · CLI tooling · Machine learning  
[View on PyPI →](https://pypi.org/project/algopipe/)
